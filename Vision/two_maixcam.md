# 两台 MaixCAM 协作系统设计文档

## 系统架构

```
STM32 <---UART---> [上位机MaixCAM] <---WiFi AP + TCP---> [下位机MaixCAM]
                    main_maixcam.py                      Ci_maixcam.py
                    自学习分类 + 匹配                     舵机扫描 + OCR
```

## 角色定义

| 角色 | 设备 | 功能 |
|------|------|------|
| 上位机 MaixCAM | main_maixcam.py | WiFi AP热点、触摸屏UI、自学习分类、TCP服务端、UART通信STM32 |
| 下位机 MaixCAM | Ci_maixcam.py | WiFi连接上位机、舵机旋转5个位置、OCR识别数字1-5、TCP客户端 |

## 自学习分类模型映射

| Class编号 | 颜色 | 对应物品 |
|-----------|------|----------|
| class1 | 黄色 | 黄豆 |
| class2 | 绿色 | 绿豆 |
| class3 | 白色 | 白芸豆 |

## 完整工作流程

### 第一阶段：初始化
1. 上位机上电 → 启动WiFi AP热点（SSID: maixcam, 密码: 12345678, IP: 192.168.66.1）
2. 下位机上电 → 连接上位机WiFi → TCP连接上位机 192.168.66.1:9090
3. 上位机屏幕显示 "Slave: OK" + "START" 按钮

### 第二阶段：启动扫描
4. 用户点击上位机屏幕 "START" 按钮
5. 上位机通过 TCP 发送 `START` 给下位机
6. 上位机通过 UART 发送 `start` 给 STM32
7. 下位机收到 START → 舵机旋转到5个位置 → 每位置拍30帧OCR → 投票出最终数字

### 第三阶段：物品分类（3次）
8. 上位机等待 STM32 发送 `s` 字符
9. 收到 `s` → 上位机对当前画面进行30帧自学习分类 → 投票取最可靠结果
10. 分类完成 → 通过 UART 发送 `CLASS:<n>` 给 STM32（n=分类结果编号）
11. 重复步骤 8-10，共3次
12. 分类结果存入数组，如 [2, 1, 3] 表示：
    - 第1次：class2（绿豆）
    - 第2次：class1（黄豆）
    - 第3次：class3（白芸豆）

### 第四阶段：匹配
13. 3次分类完成后，上位机通过 TCP 发送 `QUERY` 给下位机
14. 下位机返回 OCR 扫描结果，如 [5, 3, 1, 2, 4] 表示：
    - 位置1识别出数字5
    - 位置2识别出数字3
    - 位置3识别出数字1
    - 位置4识别出数字2
    - 位置5识别出数字4
15. 上位机进行匹配计算：找每个分类结果在 OCR 结果中第一次出现的位置（1-based）

### 第五阶段：输出结果
16. 匹配结果发送给 STM32，格式为 `MATCH:<a>,<b>,<c>`
17. 屏幕显示结果 + "RESET" 按钮

## 匹配算法详解

```
分类结果 cls = [2, 1, 3]
OCR结果  ocr = [5, 3, 1, 2, 4]

匹配过程：
  cls[0]=2 → 在 ocr 中找 2 → ocr[3]=2 → 位置=4（1-based）
  cls[1]=1 → 在 ocr 中找 1 → ocr[2]=1 → 位置=3（1-based）
  cls[2]=3 → 在 ocr 中找 3 → ocr[1]=3 → 位置=2（1-based）

最终结果 match = [4, 3, 2]
含义：第1次分类的物品在位置4，第2次在位置3，第3次在位置2
```

## UART 通信协议

### 上位机 → STM32
| 消息 | 含义 |
|------|------|
| `start` | 上位机已启动，等待STM32发送"s" |
| `CLASS:<n>` | 分类完成，n=class编号(1/2/3) |
| `MATCH:<a>,<b>,<c>` | 最终匹配结果 |
| `ERR:NO_OCR` | OCR获取失败 |
| `READY` | 上位机就绪 |

### STM32 → 上位机
| 消息 | 含义 |
|------|------|
| `s` | 通知上位机可以开始当前画面分类 |

## TCP 通信协议

### 上位机 → 下位机
| 消息 | 含义 |
|------|------|
| `START` | 开始扫描 |
| `QUERY` | 查询OCR结果 |
| `PING` | 心跳检测 |

### 下位机 → 上位机
| 消息 | 含义 |
|------|------|
| `CONNECTED` | 下位机已连接 |
| `ACK:START` | 确认开始扫描 |
| `RESULTS:<a>,<b>,<c>,<d>,<e>` | OCR扫描结果 |
| `SCANNING` | 仍在扫描中 |
| `PONG` | 心跳回复 |
